# Python Forge review source and evidence

This repository contains two roadmap PDFs:

- `Python_Forge_Comprehensive_Review_and_Roadmap.pdf` is the original artifact and is preserved unchanged.
- `Python_Forge_Comprehensive_Review_and_Roadmap_Updated.pdf` is the evidence-based revision generated by `tooling/generate_updated_roadmap_pdf.py`.

The original PDF exposes readable metadata, but its body is stored in compressed streams that were not reliably extractable during the review. The updated PDF therefore records repository-source evidence, validation commands, build artifacts, and known evidence limitations instead of claiming a line-by-line reproduction of the original body.

`docs/evidence-index.json` is the machine-readable source of truth for the captured evidence. It records the source-document and runtime-artifact SHA-256 values, the curriculum manifest and canonical content hash, the phase status snapshot, and the source files or commands supporting each phase. Run the verifier before the normal quality gates:

```text
python tooling/verify_roadmap_evidence.py --report build/roadmap-evidence-report.json
```

For a connected Android device, run the non-destructive qualification harness after building the debug APK:

```text
python tooling/run_android_smoke.py --serial DEVICE_SERIAL --output-dir build/android-smoke
```

It uses `adb install -r`, force-stops and relaunches the package, then captures a PID check, UI hierarchy, screenshot, logcat, and a JSON result. It does not clear application data or claim that a full execution/device matrix has passed.


Evidence classes used by the roadmap are:

- `local`: reproducible from the current checkout.
- `manual`: observed during a controlled local device or UI smoke test.
- `hosted`: produced by a hosted CI or release service.
- `blocked`: requires credentials, external access, a target platform, or a product/architecture decision.

The current worktree snapshot is intentionally recorded as dirty because this roadmap work is being developed on top of existing uncommitted changes. No file in this evidence slice clears, resets, or overwrites unrelated work.
