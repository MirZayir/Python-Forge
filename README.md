A premium, gamified mobile application designed for learning Python from scratch through interactive coding missions, real-time code execution, and modular progression.

---

## 🎨 What's New in v0.5.0

* **American Vintage Bento UI**: Redesigned dashboard, profile, curriculum, and mission screens featuring matte cream (`#E8D8C9`) surfaces, retro orange (`#F3701E`) accents, and responsive bento grids.
* **Smart Code Editor Engine**:
  * **Dynamic Line Numbering Gutter**: Real-time line counters that automatically expand ahead as you write code.
  * **Fixed Template Placeholders**: Translucent, non-erasable starter code blocks that protect mission instructions.
  * **Zero Typing Latency**: Performance-optimized text controller operating smoothly at native device refresh rates.
  * **Predictive Keyboard Integration**: Full support for native keyboard suggestion bars while typing.
* **Robust Code Validation**: Upgraded `AnswerValidator` with comment stripping, quote normalization, and whitespace handling to eliminate false failure checks.
* **Seamless Next-Mission Routing**: Direct mission-to-mission transitions via the completion modal without returning to the dashboard.

---

## ✨ Features

- 🎯 **Interactive Coding Missions**: Hands-on Python challenges ranging from variables to data structures.
- ⚡ **Local Code Execution Engine**: Instant stdout output and evaluation.
- 🏆 **Learner Profile & Gamification**: Track XP, level progression, completed missions, and achievement badges.
- 📚 **Structured Curriculum**: Multi-module learning path designed for step-by-step mastery.

## 🛠 Tech Stack

* **Framework**: Flutter (Dart)
* **Architecture**: Feature-First Clean Architecture
* **State Management**: Reactive State / Provider
* **Storage**: Local persistence for mission completion and learner progress
